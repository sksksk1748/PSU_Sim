# 伺服器電源拆解室 (PSU_Sim)

用瀏覽器就能玩的 3D 教學模型，用來認識伺服器電源 (PSU) 與電池備援單元 (BBU) 的內部構造、能量流動與韌體更新。整個專案只有一個 `index.html`。

**線上版：<https://sksksk1748.github.io/PSU_Sim/>**（每次推送到 `main` 會由 GitHub Actions 自動重新部署）

## 機種

| 機種 | 重點 |
|---|---|
| 3 kW · 12 V CRPS | 雙 AC 輸入 + ATS、橋式整流 + PFC、全橋 LLC、同步整流、金手指輸出 |
| 4.4 kW · 52 V 資料中心 | 雙 AC 輸入 + ATS、無橋圖騰柱 PFC (GaN)、2 相交錯 LLC、100–150 V SR、熱插拔、52 V 匯流排夾 |
| BBU 電池備援 | 14S8P 鋰電芯、BMS（保護 MOSFET、均衡、庫侖計）、雙向 Buck-Boost、預充電路 |

## 模式

- **探索**：點擊零件看說明、規格與現場小知識；標籤可切換「零件 / 細節」，細節標籤會自動避開重疊。
- **能量流**：粒子沿能量路徑流動，每一級都有示波器波形（BBU 可切換充電 / 放電方向）。
- **ATS / 掉電 / 充放電模擬**：切斷 AC，觀察 ATS 切換、Bulk 保持時間、BBU 接手，以及 SOC、CC/CV 充電。
- **FW 更新**：模擬 ATS / Primary / Secondary 三顆 MCU 的韌體更新，可切換 **CAN**（UDS + ISO-TP，真實 CAN 2.0A 位元波形含 CRC-15 與位元填充）或 **PMBus**（SMBus 交易、PEC CRC-8、SCL / SDA 波形），並可注入通訊錯誤、CRC 錯誤與斷電。
- **TE 測試**（4.4 kW · 52 V 機種）：照 TE 測試計畫執行 93 個測項（輸入、ATS、效率、輸出、保護、熱、通訊 / FW、安規、EMC、機櫃 BBU 系統），每項都有測試條件、判定、儀器、3D 量測點，以及示波器波形 / 頻譜 / 溫升 / 效率曲線等量測畫面。樣品藏有故障（Bulk 電容衰退、ATS 繼電器過慢、Y 電容漏件…），遇到 FAIL 要在 3D 模型上點出原因零件、換料後重測；可匯出 CSV 測試報告。
- **測驗**：讀題後在 3D 模型上點出正確零件。

## 怎麼開

直接用瀏覽器開啟 `index.html` 即可（需要網路，從 cdn.jsdelivr.net 載入 three.js 0.160.0）。

如果瀏覽器擋住本機檔案的模組載入，可在資料夾內啟動任一靜態伺服器，例如：

```bash
python -m http.server 8000
```

再開 <http://localhost:8000>。網址後面加 `#crps12`、`#dc52` 或 `#bbu` 可以直接指定機種。

## 說明

這是依公開架構製作的通用示意模型，不代表任何特定廠商或客戶的產品。尺寸、零件數量、MCU 型號、通訊協定細節（CAN ID、PMBus 廠商自訂指令 0xF0–0xF7、金鑰演算法）與各項數值都經過簡化，僅供學習使用。
